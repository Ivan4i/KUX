## Anatomy Cross-Links — Component Relationships & Shared Subcomponents

### Notification/Alert/Banner Cluster
- **Shared:** Status badges (error, warning, success, info) · Dismiss controls · Text content + icons
- **Variants Overlap:** Filled, Light, Lighter, Stroke styles appear in Alert, Banner, and standalone Badge
- **Connections:**
  - Alert/Notification/Toast → Banner (both support style variations)
  - Badge → Used within Alert/Notification badges to denote status
  - Button Group → Can be paired with Alert/Notification for action grouping

### Input Controls Cluster
- **Shared:** Label associations · Focus states · Validation feedback · Disabled state handling
- **Components:** Text Input, Text Area, Select, Checkbox, Radio, Switch, Slider, Time Picker, Date Picker
- **Connections:**
  - Text Input ↔ Text Area (multi-line variant)
  - Select ↔ Dropdown (similar interaction patterns)
  - Checkbox ↔ Radio (binary/single vs. multi-select)
  - Date Picker + Time Picker → Can combine for datetime input

### Navigation Cluster
- **Shared:** Active/inactive states · Icon + text display · Collapsible sections
- **Components:** Sidebar Navigation, Topbar Navigation, Tab Menu, Button Group, Segmented Control
- **Connections:**
  - Sidebar + Topbar → Compose full app layout
  - Segmented Control ↔ Tab Menu (similar toggle behavior)
  - Button Group + Segmented Control (both organize discrete options)

### Feedback/Display Cluster
- **Shared:** Icons · Status indicators · Color coding · Dismissal
- **Components:** Toast, Notification, Badge, Progress Bar, Rating, Tag
- **Connections:**
  - Badge → Appears in Activity Feed as status indicator
  - Rating ↔ Badge (both indicate status/quality)
  - Progress Bar → Often paired with modal/drawer for long-running tasks

### Modal/Overlay Cluster
- **Shared:** Backdrop · Focus management · Close control · Title/description areas
- **Components:** Modal, Drawer, Popover
- **Connections:**
  - Modal ↔ Drawer (different interaction contexts)
  - Popover → Lightweight alternative to Modal

### Data Representation Cluster
- **Shared:** Structured layout · Sorting/filtering controls · Pagination
- **Components:** Table, Activity Feed, Pagination, Filter
- **Connections:**
  - Pagination ↔ Table (for large datasets)
  - Filter + Table (narrowing data)
  - Activity Feed + Pagination (sequential content)

### Floating Content Cluster
- **Shared:** Positioning logic · Trigger mechanisms · Dismissal
- **Components:** Tooltip, Popover, Dropdown, Command Menu
- **Connections:**
  - Tooltip (read-only) vs. Popover (interactive)
  - Dropdown + Command Menu (both reveal actions)
