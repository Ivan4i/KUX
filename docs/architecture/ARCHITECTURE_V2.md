## 📊 NOTION — CRM БАЗА ДАННЫХ

### Назначение

Notion — это **ХРАНИЛИЩЕ ДАННЫХ для рассылок**, а не система управления. Он служит:

- 📋 **Базой контактов** (ФИО, номера телефонов, email)
- 💬 **Шаблонами сообщений** (которые AI будет адаптировать)
- 🎯 **Метаинформацией** (какие каналы, приоритеты, статусы)
- 📁 **Импортом данных** (загрузить 1000 контактов в одной операции)

### Структура БД в Notion

#### **Таблица 1: Contacts (Контакты)**

| ID | ФИО | Телефон | Email | Статус | Тип_Контакта | Регион | Дата_создания |
|----|-----|---------|-------|--------|--------------|--------|---------------|
| 1 | Иван Петров | +79991234567 | ivan@mail.ru | Active | Lead | РФ | 2025-12-01 |
| 2 | Мария Сидорова | +79997654321 | maria@gmail.com | Processed | Customer | РФ | 2025-12-01 |

#### **Таблица 2: Message Templates (Шаблоны сообщений)**

| ID | Название | Текст | Переменные | Канал | Версия | Дата_обновления |
|----|----------|-------|-----------|-------|--------|-----------------|
| T1 | Приветствие | "Привет, {name}! Давай поговорим о..." | {name}, {offer} | WhatsApp | v1 | 2025-12-09 |
| T2 | Follow-up | "Помните нас? Вот новое..." | {name}, {product} | Telegram | v1 | 2025-12-09 |

#### **Таблица 3: Campaigns (Рассылки)**

| ID | Название | Status | Контакты | Шаблон | Канал | Начало | Конец | Результат |
|----|----------|--------|----------|--------|-------|--------|-------|-----------|
| C1 | Зимняя распродажа | Running | 500 | T1 | WhatsApp | 2025-12-09 | 2025-12-15 | 120 отправлено |
| C2 | VIP follow-up | Pending | 100 | T2 | Telegram | 2025-12-10 | 2025-12-12 | — |

### Интеграция с веб-интерфейсом

**Процесс:**

1. **В веб-интерфейсе** ты нажимаешь **"📥 Import from Notion"**
2. **Система** скачивает данные из таблиц Notion
3. **В приложении** ты создаёшь **Scenario** (сценарий):
   ```
   Сценарий: "Декабрьская рассылка"
   
   Шаг 1: Импортировать контакты из Notion (Campaigns → C1)
   Шаг 2: Для каждого контакта:
     - Открыть WhatsApp
     - Сгенерировать сообщение через AI (по шаблону T1)
     - Отправить
   Шаг 3: Обновить статус в Notion (Campaign C1 → "Completed")
   ```

```python
class NotionClient:
    """Клиент для работы с Notion"""

        """Скачать все контакты из таблицы Contacts"""

    async def get_message_templates(self) -> List[dict]:
        """Получить все шаблоны сообщений"""
        
    async def get_campaigns(self) -> List[dict]:
        """Получить список рассылок со статусами"""

        """Обновить статус рассылки (Running → Completed)"""
        
    async def log_message_sent(self, campaign_id: str, contact_id: str, 
                               channel: str, timestamp: datetime):
        """Залогировать отправленное сообщение"""
```

## 🎯 СИСТЕМА СЦЕНАРИЕВ

### Что такое сценарий?

**Сценарий** — это **последовательность действий**, которые выполняются одно за другим.

### Структура сценария

```
Сценарий:
  ├─ Название
  ├─ Описание
  ├─ Шаги (Step 1, Step 2, Step 3, ...)
  │   └─ Каждый шаг:
  │       ├─ Тип (WhatsApp, Instagram, LinkedIn, и т.д.)
  │       ├─ Промт (что делать)
  │       ├─ Параметры (видео, текст, конфиг)
  │       ├─ Условия (если что-то, то...)
  │       ├─ Пауза после (сколько секунд/минут)
  │       └─ Обработка ошибок (повтор, пропустить, отменить)
  ├─ Опции выполнения
  │   ├─ По расписанию (когда запустить)
  │   ├─ Уведомления (кому оповестить)
  │   └─ Повторы (при ошибке)
  └─ История выполнений
```

### Использование промтов в агентах

```python
from ..prompts.instagram_prompts import (
    INSTAGRAM_POST_REEL,
    INSTAGRAM_WARMUP_ACCOUNT,
    INSTAGRAM_SEND_DM_CAMPAIGN
)

class InstagramAgent(BaseAgent):
    """Агент Instagram с гибкими промтами"""
    
    async def post_reel(self, 
                       video_path: str,
                       custom_description: str = None,
                       tags: str = None,
                       hashtags: str = None,
                       **custom_config) -> dict:
        """Выложить рилс"""
        
        # 1. Получить шаблон промта
        template = INSTAGRAM_POST_REEL
        
        # 2. Заполнить переменные
        prompt = template.prompt_text.format(
            video_path=video_path,
            custom_description=custom_description or "[генерировать через AI]",
            tags=tags or "[не указано]",
            hashtags=hashtags or "[не указано]",
            ai_generate_hashtags=custom_config.get('ai_generate_hashtags', True),
        )
        
        # 3. Объединить конфиг (шаблон + пользовательский)
        config = {**template.config, **custom_config}
        
        # 4. Выполнить промт через AI агента
        result = await self.execute_prompt(
            prompt=prompt,
            config=config,
            llm_model=config.get('ai_model', 'gemini')
        )
        
        return result
    
    async def warmup_account(self,
```

| Критерий | AirDroid | VNC (droidVNC-NG) |
|----------|----------|------------------|
| **Цена** | $4/мес (Premium) | 🆓 Бесплатно |
| **Скорость** | ~500ms задержка | ~100ms задержка (быстрее) |
| **Доступ** | Через их сервера | Прямое соединение через VPN |
| **Полный контроль** | Есть ограничения | ✅ Полный контроль |
| **iPhone доступ** | ✅ Есть | ✅ Есть (через VNC Viewer) |
| **Резервный способ** | Полезен при сбое VPN | Основной способ |

```python
class VNCManager:
    """Управляет VNC соединениями"""
    
    def __init__(self):
        self.vnc_connections = {}  # device_id -> VNC инфо
    
    async def start_vnc_server(self, device: Device):
        """
        Запустить VNC сервер на устройстве
        
        Требует:
        - droidVNC-NG установлен
        - Tailscale VPN работает
        """
        
        # 1. Проверить что droidVNC-NG установлен
        adb_serial = device.adb_serial
        
        # 2. Запустить VNC Server
        cmd = f"adb -s {adb_serial} shell am start -n com.example.droidvnc_ng/.MainActivity"
        os.system(cmd)
        
        # 3. Получить IP через ADB
        # (droidVNC-NG выводит IP в логи или можно использовать Tailscale IP)
        
        # 4. Сохранить в конфиг
        self.vnc_connections[device.id] = {
            'ip': device.tailscale_ip,
            'port': 5900,
            'password': device.vnc_password,  # из конфига
            'status': 'running'
        }
    
    def get_vnc_url(self, device_id: str) -> str:
        """Получить URL для подключения к VNC"""
        if device_id not in self.vnc_connections:
            return None
        
        vnc = self.vnc_connections[device_id]
        return f"vnc://{vnc['ip']}:{vnc['port']}"
```

### Архитектура

**Система автоматически переключается между LLM** если один не работает.

```

```

### Реализация

**backend/src/integrations/llm_client.py** (обновленный)

```python
import asyncio
from typing import Optional
from loguru import logger

class LLMClient:
    """
    Клиент LLM с fallback механизмом
    Поддерживает: Gemini, Puter.js, Ollama
    """
    
    def __init__(self):
        self.gemini_api_key = os.getenv("GEMINI_API_KEY")
        self.puter_api_key = os.getenv("PUTER_API_KEY")
        self.ollama_base_url = os.getenv("OLLAMA_BASE_URL", "http://localhost:11434")
        
        # Инициализировать клиентов
        self.gemini_client = None
        self.ollama_client = None
        
        self._init_clients()
    
    def _init_clients(self):
        """Инициализировать доступные LLM клиентов"""
        
        # Gemini
        if self.gemini_api_key:
            try:
                import google.generativeai as genai
                genai.configure(api_key=self.gemini_api_key)
                self.gemini_client = genai.GenerativeModel('gemini-3-pro')
                logger.info("✅ Gemini initialized")
            except Exception as e:
                logger.warning(f"⚠️ Gemini init failed: {e}")
        
        # Ollama
        try:
            import ollama
            # Проверить что Ollama работает
            response = requests.get(f"{self.ollama_base_url}/api/tags")
            if response.status_code == 200:
                self.ollama_client = ollama.Client(base_url=self.ollama_base_url)
                logger.info("✅ Ollama initialized")
        except Exception as e:
            logger.warning(f"⚠️ Ollama not available: {e}")
    
    async def call_llm(self, prompt: str, 
                      system_prompt: str = None,
                      temperature: float = 0.7,
                      max_tokens: int = 2048,
                      preferred_model: str = None) -> str:
        """
        Вызвать LLM с автоматическим fallback
        
        Args:
            prompt: основной промт
            system_prompt: системный промт
            temperature: randomness (0-1)
            max_tokens: максимум токенов
            preferred_model: предпочтительная модель (gemini/puter/ollama)
        
        Returns:
            ответ от LLM
        """
        
        # Порядок попыток
        models_to_try = []
        
        if preferred_model == 'gemini':
            models_to_try = ['gemini', 'puter', 'ollama']
        elif preferred_model == 'puter':
            models_to_try = ['puter', 'gemini', 'ollama']
        elif preferred_model == 'ollama':
            models_to_try = ['ollama', 'puter', 'gemini']
        else:
            # Автоматический выбор: gemini → puter → ollama
            models_to_try = ['gemini', 'puter', 'ollama']
        
        # Пробовать каждую модель
        for model_name in models_to_try:
            try:
                if model_name == 'gemini' and self.gemini_client:
                    logger.info(f"🤖 Trying Gemini...")
                    result = await self._call_gemini(prompt, system_prompt, temperature, max_tokens)
                    logger.info(f"✅ Gemini succeeded")
                    return result
                
                elif model_name == 'puter':
                    logger.info(f"🤖 Trying Puter.js...")
                    result = await self._call_puter(prompt, system_prompt, temperature, max_tokens)
                    logger.info(f"✅ Puter.js succeeded")
                    return result
                
                elif model_name == 'ollama' and self.ollama_client:
                    logger.info(f"🤖 Trying Ollama locally...")
                    result = await self._call_ollama(prompt, system_prompt, temperature, max_tokens)
                    logger.info(f"✅ Ollama succeeded")
                    return result
            
            except Exception as e:
                logger.warning(f"❌ {model_name} failed: {e}")
                continue
        
        # Если все модели отказали
        raise RuntimeError("❌ All LLM models failed. Check API keys and connections.")
    
    async def _call_gemini(self, prompt: str, system: str, temp: float, tokens: int) -> str:
        """Вызвать Gemini API"""
        full_prompt = f"{system}\n\n{prompt}" if system else prompt
        response = await asyncio.to_thread(
            self.gemini_client.generate_content,
            full_prompt
        )
        return response.text
    
    async def _call_puter(self, prompt: str, system: str, temp: float, tokens: int) -> str:
        """Вызвать Puter.js API (Claude Sonnet 4.5)"""
        
        # Puter.js использует OpenAI-compatible API
        import httpx
        
        headers = {
            "Authorization": f"Bearer {self.puter_api_key}",
            "Content-Type": "application/json"
        }
        
        messages = []
        if system:
            messages.append({"role": "system", "content": system})
        messages.append({"role": "user", "content": prompt})
        
        payload = {
            "model": "claude-3.5-sonnet",  # или "gpt-4", "gemini-3-pro"
            "messages": messages,
            "temperature": temp,
            "max_tokens": tokens
        }
        
        async with httpx.AsyncClient() as client:
            response = await client.post(
                "https://api.puter.js.org/v1/chat/completions",
                json=payload,
                headers=headers
            )
            
            if response.status_code != 200:
                raise RuntimeError(f"Puter API error: {response.text}")
            
            data = response.json()
            return data['choices'][0]['message']['content']
    
    async def _call_ollama(self, prompt: str, system: str, temp: float, tokens: int) -> str:
        """Вызвать локальную Ollama (Llama 3.2 Vision)"""
        
        full_prompt = f"{system}\n\n{prompt}" if system else prompt
        
        response = await asyncio.to_thread(
            self.ollama_client.generate,
            model="llama3.2-vision",
            prompt=full_prompt,
            temperature=temp,
            num_predict=tokens
        )
        
        return response['response']
```
