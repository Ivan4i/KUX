## 🐛 COMMON ISSUES & SOLUTIONS

| Issue | Solution | File |
|-------|----------|------|
| Docker not installed | `brew install docker` | 101_TROUBLESHOOTING_RUNBOOK.md |
| Port already in use | `lsof -i :8000` then kill | 101_TROUBLESHOOTING_RUNBOOK.md |
| USB devices not detected | Run `adb kill-server && adb start-server` | 71_USB_ADB_PERSISTENT_CONNECTION.md |
| Database connection failed | Check PostgreSQL running | 101_TROUBLESHOOTING_RUNBOOK.md |
| Redis connection error | `docker-compose restart redis` | 101_TROUBLESHOOTING_RUNBOOK.md |
| Celery workers not active | `docker-compose logs celery-worker` | 92_QUEUE_AND_SCHEDULER.md |
| WebSocket failing | Check `VITE_WS_URL` in .env | 82_DASHBOARD_REALTIME.md |
| API CORS errors | Verify `CORS_ORIGINS` config | 90_BACKEND_ARCHITECTURE.md |
